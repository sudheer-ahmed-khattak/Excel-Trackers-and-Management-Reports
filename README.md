## Management Action & Follow-Up Tracker

A professional Excel-based action tracking and executive follow-up tool designed for management, project, and administrative environments.

### Key Features

- Executive KPI dashboard
- Total, open, overdue and high-priority action monitoring
- Completion percentage tracking
- Action status overview
- Priority distribution analysis
- Department-wise follow-up
- Open action exposure by department
- Dynamic aging and due-date monitoring
- Management control notes
- Visual alerts and conditional formatting
