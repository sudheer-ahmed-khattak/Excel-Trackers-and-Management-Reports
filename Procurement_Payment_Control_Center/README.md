# Procurement Payment Control Center

## Overview

This dashboard demonstrates procurement workflow monitoring, payment tracking, vendor exposure, outstanding commitments, and financial reporting using Power BI. It provides executive management with a consolidated view of procurement performance and payment status.

> **Note:** All information shown in this project is synthetic/anonymized and created exclusively for portfolio demonstration purposes.
