## 🎯 The Challenge

Heavy equipment comes from several suppliers and moves between projects. Without a register, idle or released equipment keeps getting paid for.

## ✅ The Solution

A Power BI dashboard on an Excel equipment register that shows current vs released equipment, ownership, supplier split, type distribution and project allocation.

<p align="center"><img src="Fleet_Equipment_Operations_Dashboard_Preview.png" width="100%" alt="Fleet & Equipment Operations Dashboard preview" /></p>

## 📦 What's Inside

| Component | What it does |
|---|---|
| **Power BI report** | Current vs released, ownership, supplier and type views, project allocation |
| **Excel register** | Working and Released equipment lists |
| **PDF report** | Print-ready dashboard |

## ⭐ Key Features

- ✅ Current vs released equipment at a glance
- ✅ Ownership split: owned vs rented by supplier
- ✅ Equipment type distribution
- ✅ Project-wise allocation and released equipment by project
- ✅ Supports rental cost control
