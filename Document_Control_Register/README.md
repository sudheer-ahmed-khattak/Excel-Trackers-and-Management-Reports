# 📁 Document Control Register

<p align="center"><img src="Document_Control_Register_Preview.png" width="100%"></p>

A document control register for a construction project – every drawing, method statement, material submittal, report, procedure and calculation in one place, with **instant search**, review-code tracking and an executive dashboard.

## 🎯 Business Problem
Hundreds of documents move between the contractor and the consultant. Without one register, teams lose track of the latest revision, which documents need resubmission, and how long the consultant has been reviewing them.

## ✅ Solution
| Sheet | What it does |
|---|---|
| **Dashboard** | KPI cards (total, approved, under review, resubmit, overdue > 14 days), review status by document type and discipline, charts |
| **Search** | Type any part of a document number, title, type, discipline, transmittal or status – matching documents and their file locations appear instantly |
| **Document Register** | 240 documents with number, title, type, discipline, revision, submission date, transmittal, reviewer, review code, response date, days in review, next action and file location |

## ⚙️ Key Features
- Review codes colour-coded: **Code A** Approved, **Code B** Approved with Comments, **Code C** Revise & Resubmit, **Code D** Rejected, **Under Review**
- **Days in Review** calculated automatically – documents waiting more than 14 days turn red
- Formula-driven search with result count, no filters to reset
- Structured document numbering (Project–Company–Discipline–Type–Sequence) and file-location path for every record

## 🛠️ Tools
Microsoft Excel • COUNTIFS / INDEX / SMALL / SEARCH formulas • Conditional Formatting • Data Validation • Excel Charts

## 📥 How to Use
1. Download **Document_Control_Register.xlsx**
2. Add new documents at the bottom of **Document Register** and update the review code when the consultant responds
3. Use **Search** to find any document in seconds; the **Dashboard** updates automatically

📄 A one-page PDF of the dashboard is included: **Document_Control_Register.pdf**

> 🛡️ All project names, document numbers, transmittals, companies and reviewers are fictional demo data.
